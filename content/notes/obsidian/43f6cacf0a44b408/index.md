## 先判断走哪条解题路

给电荷分布求场：对称性不足时 [电场叠加与连续电荷积分](/my-web/notes/obsidian/f8d9b9949f706896/) → [均匀带电圆环轴线场强](/my-web/notes/obsidian/581bfd027b33ab9b/) → [有限带电直棒](/my-web/notes/obsidian/02e13da3fb3fda17/) → [带电圆盘与圆环分割](/my-web/notes/obsidian/148759da30c3ab16/)；球/柱/平面对称时 [高斯定理与对称性判断](/my-web/notes/obsidian/a7515dd943226c39/) → [球对称电荷的分区电场与电势](/my-web/notes/obsidian/61c5fb0adfb7b15d/) → [无限长线与圆柱对称场](/my-web/notes/obsidian/bf68bff3575ef0c4/) → [无限大平面与多平面叠加](/my-web/notes/obsidian/e808e3a51757b08c/)

求电势与做功：[电势与电势叠加](/my-web/notes/obsidian/09dc45185b27d0e3/) → [电场与电势的梯度关系](/my-web/notes/obsidian/8f9705eb2776bc64/) → [静电力做功与电势能](/my-web/notes/obsidian/e069de2496b8452b/)

有金属、空腔或接地：[导体静电平衡](/my-web/notes/obsidian/58d990316008085d/) → [导体空腔与感应电荷](/my-web/notes/obsidian/7ef2a5f9ba7e6f23/) → [接地条件与导体电势](/my-web/notes/obsidian/10da961e673c07ae/)

有介质或求电容、能量：[电介质极化与极化强度](/my-web/notes/obsidian/9038a67e0032fe4c/) → [电位移D与介质高斯定理](/my-web/notes/obsidian/a7b196bda29841f1/) → [电容定义与平行板电容](/my-web/notes/obsidian/fb9f374dfa570d82/) → [电容串并联与混合介质](/my-web/notes/obsidian/ea2bc1f82c5e399a/) → [静电能量与能量密度](/my-web/notes/obsidian/7ae1f1f4ff41bd7b/) → [插入介质时固定Q还是固定U](/my-web/notes/obsidian/24e59c001e2459b3/)

## 静电场基本工具

| 知识点 | 何时打开 |
| --- | --- |
| [库仑定律与电场强度](/my-web/notes/obsidian/5db3f92103115401/) | 先分清场源电荷和检验电荷，再定矢量方向。 |
| [电场叠加与连续电荷积分](/my-web/notes/obsidian/f8d9b9949f706896/) | 几何不够对称时，把电荷切小、投影，再积分。 |
| [电通量](/my-web/notes/obsidian/be46d9ab8747aa2d/) | 通量数的是穿过曲面的有向场，不是曲面上的场强总量。 |
| [高斯定理与对称性判断](/my-web/notes/obsidian/a7515dd943226c39/) | 先证明能把E提出积分，再写ES。 |

## 不同几何与对称性

| 知识点 | 何时打开 |
| --- | --- |
| [均匀带电圆环轴线场强](/my-web/notes/obsidian/581bfd027b33ab9b/) | 圆环各元距离相同，横向分量抵消，保留轴向。 |
| [半圆环的场强与电势](/my-web/notes/obsidian/cfa586bb35f32867/) | 半圆环缺少另一半的抵消，圆心场强通常非零。 |
| [有限带电直棒](/my-web/notes/obsidian/02e13da3fb3fda17/) | 有限直棒通常用积分；无限长才直接用柱对称结论。 |
| [带电圆盘与圆环分割](/my-web/notes/obsidian/148759da30c3ab16/) | 圆盘切成同心细圆环，复用圆环轴线公式。 |
| [球对称电荷的分区电场与电势](/my-web/notes/obsidian/61c5fb0adfb7b15d/) | 球壳和实心球的内部场不同，先求包围电荷。 |
| [无限长线与圆柱对称场](/my-web/notes/obsidian/bf68bff3575ef0c4/) | 同轴圆柱侧面有通量，两个端面的通量为零。 |
| [无限大平面与多平面叠加](/my-web/notes/obsidian/e808e3a51757b08c/) | 先区分非导体薄电荷面和导体表面，避免差一个2。 |
| [补偿法与挖孔电荷分布](/my-web/notes/obsidian/3264ea7c2054acbc/) | 缺一块的均匀分布，写成完整分布加反号的一块。 |
